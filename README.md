# 🔨 PrediKit
This complete tool provides a professional, user-friendly interface for machine learning tasks with the added capability to download predictions, making it perfect for both learning and production use!

## ✨ Features

- 📊 Upload Excel data with automatic feature/target detection
- 🤖 Train multiple models (DT, RF, SVM, DNN)
- 🎯 Automatic task detection (Classification/Regression)
- 📈 Comprehensive evaluation metrics and visualizations
- 💾 Download predictions as Excel files
- 🎨 Beautiful, responsive web interface

## 🚀 Quick Start

### Installation

```bash
# Clone the repository
git clone https://github.com/pascme05/PrediKit.git
cd PrediKit

# Install dependencies
pip install -r requirements.txt

# Run the application
python app.py
